## 1. Приказ ФХД — образец 2024

**Файл:** `IGNORE/documents/вид проверки_ ФХД/приказы/Приказ 20П-358_Изм в приказ 20П-318.docx`  
**Тип документа:** Приказ министра «О внесении изменения» (ФХД)  
**Дополнительно:** `Приказ 20П-318_ФХД ДД_Солнечногорский.odt` — аналогичный первоначальный приказ в формате ODT

### Поля страницы (A4 210×297 мм)
| Поле | Значение |
|------|----------|
| Левое | **20,0 мм** |
| Правое | **10,1 мм** |
| Верхнее | **20,0 мм** |
| Нижнее | **20,0 мм** |

### Основной шрифт (стиль Normal / Standard)
- **Гарнитура:** Times New Roman
- **Размер:** 12 pt (основной текст), 14 pt (заголовок и основное содержание)
- **Жирный:** не используется в основном тексте; заголовки разделов — Bold

### Межстрочный интервал
- **Основной текст:** 1,15× (276 twips, режим `auto`)
- **Акт (Шатурский):** 1,00× (240 twips, режим `auto`)

### Отступ первой строки
- **Абзацы основного текста:** 12,5 мм (точное значение в XML: 709 twips)
- **Блок реквизитов:** нет отступа

### Выравнивание
- **Основной текст:** по ширине (`justify` / `both`)
- **Заголовок документа (тема):** по центру (`center`)
- **Строка подписи ФИО:** по правому краю (`right`)

### Структура шапки документа

Приказы Министерства используют **бланк организации** — первые 10–11 пустых строк в теле документа оставлены под бланк. Документ печатается на готовых фирменных бланках с изображением герба и реквизитами Министерства.

```
[Строки 0-10]   Пустые (Normal, justify, 12pt по умолчанию)
                → зарезервированы под бланк организации
                → на бланке: герб, «МИНИСТЕРСТВО СОЦИАЛЬНОГО РАЗВИТИЯ
                  МОСКОВСКОЙ ОБЛАСТИ», адрес, телефон, e-mail

[Строки 11-12]  Пустые, 14pt, tab 132,5 мм/left
                → зарезервированы под дату и номер (правая часть)

[Строки 13-15]  Пустые, align=center, tab 142,5 мм/left
                → позиция «г. Красногорск» / дата

[Строки 16-17]  ТЕМА ПРИКАЗА, align=center, 14pt, 1,15x
                → многострочный заголовок (вид документа + «о чём»)

[Строки 18-20]  Пустые разделители

[Строка 21]     «ПРИКАЗЫВАЮ:» — основной текст, justify, 14pt
                → нумерованные пункты, отступ 12,5 мм
```

#### Структура шапки (ODT вариант — тот же документ):
- Поля ODT: лево 20,0 мм, право 10,1 мм, верх 12,7 мм, низ 12,7 мм
  *(верхнее/нижнее отличается от docx — вероятно, ODT является черновиком)*
- Заголовок темы выделен 14pt + Bold (в ODT)

### Структура реквизитов бланка

По данным подписанного PDF (`20П-318_ проверка ФХД ДД Солнечногорский.pdf`) и аналогии с другими документами министерства, бланк содержит:

```
ПРАВИТЕЛЬСТВО МОСКОВСКОЙ ОБЛАСТИ
МИНИСТЕРСТВО СОЦИАЛЬНОГО РАЗВИТИЯ
МОСКОВСКОЙ ОБЛАСТИ

[Адрес]  [Телефон]  [E-mail]
```

Верхняя часть бланка занимает приблизительно **55–65 мм** по высоте.

### Оформление подписи

**Формат:** в строку, с правым выравниванием (align=right), без таблицы.

```
Министр социального развития
Московской области                    А.А. Кирюхин
```

- Должность и ФИО — в одном или двух абзацах
- ФИО — в крайней правой позиции (выравнивание по правому краю, стиль Standard/Normal)
- Шрифт: Times New Roman, 12–14 pt

## 2. Акт ФХД — ГКУ СЦ Шатурский 2024

**Файл:** `IGNORE/documents/вид проверки_ ФХД/акты/Акт ГКУ СЦ Шатурский 2024.docx`

### Поля страницы (A4 210×297 мм)
| Поле | Значение |
|------|----------|
| Левое | **20,0 мм** |
| Правое | **12,5 мм** |
| Верхнее | **20,0 мм** |
| Нижнее | **20,0 мм** |

### Основной шрифт
- **Гарнитура:** Times New Roman (из стиля Standard)
- **Размер:** **14 pt** (весь документ — тексты, заголовки, таблицы)
- Стиль Normal не задаёт шрифт явно; размер задаётся через `w:sz` в runs (28 half-pt = 14pt)

### Межстрочный интервал
- **Основной текст:** **1,00×** (240 twips, `auto`) — одинарный
- Стиль Normal в этом документе задаёт `atLeast` 175 260 EMU ≈ 12,5 мм минимальная высота строки (это из-за конвертации из LibreOffice)

### Отступ первой строки
- **Абзацы основного текста:** **12,5 мм** (709 twips)
- **Заголовки разделов:** тот же 12,5 мм или нет отступа (выравнивание по центру)

### Выравнивание
- **Основной текст:** по ширине (`both`)
- **Заголовок документа «АКТ»:** по центру, 14pt
- **Заголовки разделов:** по центру, 14pt, Bold

### Структура шапки акта

В отличие от приказа, акт **не использует бланк организации**. Документ начинается непосредственно с заголовка:

```
[Строка 0]  «АКТ» — align=center, 14pt, одинарный интервал

[Строка 1]  «проверки финансово-хозяйственной» — center, 14pt

[Строка 2]  «деятельности [полное название учреждения]» — center, 14pt

[Строка 3]  Пустая

[Строка 4]  «г. Шатура      [TAB][TAB][TAB]   «30» июня 2024 года»
             — align=both, 14pt
             → место и дата через табуляторы в одну строку

[Строки 5-6] Пустые

[Строка 7]  «Во исполнение приказа...» — основной текст
```

### Оформление заголовков разделов

```
1. Характеристика деятельности Учреждения
```
- Align: CENTER
- Шрифт: 14pt, **Bold**
- Межстрочный: 1,00×
- Отступ: 12,5 мм

### Оформление подписи

**Формат:** построчно, без таблицы, выравнивание по ширине (с пробелами для имитации колонок):

```
Руководитель проверки
Главный инспектор отдела финансового контроля
деятельности подведомственных учреждений
управления финансового контроля и аудита
Министерства социального развития
Московской области                    [ПОДПИСЬ]    Иванов И.И.
```

- Должность: несколько строк, align=both, 14pt
- Подпись: через пробелы в строке, align=both
- Дата подписания: отдельная строка `«06 августа 2024 года»`, align=both, 14pt

### Таблицы
Документ содержит **20 таблиц** (данные проверки).  
Таблицы не имеют специального стиля — используют Normal с 14pt шрифтом.

- `.pdf`: `Приказ проверка МБТ Балашиха_20П-12.pdf` — подписанная МСЭД-версия (3 стр., сканировано, текст некопируемый)

### Поля страницы (A4 210×297 мм)
| Поле | Значение |
|------|----------|
| Левое | **20,0 мм** |
| Правое | **9,9 мм** (≈10 мм) |
| Верхнее | **20,7 мм** |
| Нижнее | **12,5 мм** |

*Нижнее поле меньше — документ использует нижний колонтитул (нумерация страниц).*

### Основной шрифт
- **Гарнитура:** Times New Roman (стиль Normal)
- **Размер:** **14 pt** (весь текст — заголовок, тело, подпись)
- Normal стиль: Times New Roman, 12pt базовый, но весь контент явно задан 14pt через runs

### Межстрочный интервал
- **Основной текст:** **1,15×** (276 twips, `auto`)

### Отступ первой строки
- **Абзацы основного текста:** **12,5 мм** (совпадает с приказами ФХД)

### Выравнивание
- **Основной текст:** по ширине (`both`)
- **Заголовок:** по центру
- **Блок подписи:** наследование (inherit) с пробелами

### Структура шапки

Идентична приказам ФХД:

```
[Строки 0-10]   11 пустых строк под бланк организации (12pt)

[Строки 11-12]  Пустые, 14pt, tab 132,5 мм/left
                → зарезервированы под дату/номер

[Строки 13-15]  Пустые, align=center, 14pt, tab 142,5 мм/left

[Строки 16-18]  ТЕМА ПРИКАЗА, align=center, 14pt, 1,15x
                → «О проведении плановой выездной проверки...»
                   «...городского округа Балашиха Московской области»

[Строки 19-21]  Пустые, align=center, 14pt, 1,15x

[Строка 22]     «В соответствии с...» — основание, justify, 14pt, 1,15x
```

### Нумерованные пункты приказа

```
1. Провести плановую выездную проверку...
2. Предметом Проверки определить...
3. Определить:
   срок проведения Проверки: ...
   проверяемый период: ...
4. Определить должностное лицо...
5. Для участия в проведении...
6. Утвердить прилагаемую Программу...
7. Контроль за выполнением...
```
- Нумерация: `1.\u00a0` (неразрывный пробел после точки)
- Отступ: 12,5 мм

### Оформление подписи

```
Министр социального развития
Московской области                    [ПОДПИСЬ]    А.А. Кирюхин
```

- Стиль Normal, align=inherit (наследуется)
- Межстрочный: 1,15×
- Форматирование: в строку через пробелы (без таблицы)

### Дополнение: Программа проверки (Приложение)
Документ содержит вторую часть — Программу проверки (со строки 56):
- Заголовок «ПРОГРАММА» — align=center, 14pt, Bold
- Основной текст: justify, 14pt, 1,15x, отступ 12,5 мм

## Ключевые выводы для шаблонизатора

### Общая структура всех приказов (ФХД и МБТ)

1. **Шапка-бланк**: `~55-65 мм` от начала страницы — место под готовый фирменный бланк Министерства. Реализовано как 10–11 пустых строк в теле документа. Никакого изображения в файле нет — документ печатается на готовом бланке.

2. **Строки дата/номер**: 2 строки (14pt, таб на 132,5 мм) — пустые заготовки; заполняются при создании документа.

3. **Область заголовка**: 3–5 строк (14pt, по центру, 1,15×, таб 142,5 мм). Тема приказа с обязательным переносом в нескольких строках.

4. **Разделитель**: 2–3 пустые строки между заголовком и основанием.

5. **Основание + нумерованные пункты**: justify, 14pt, 1,15×, отступ 12,5 мм.

6. **Подпись**: отдельный блок из 2–4 строк через пробелы, нет таблицы.

### Отличие акта от приказа
- Акт начинается без бланка — с заголовка «АКТ» по центру жирным
- Межстрочный в акте: **одинарный (1,00×)**, в приказе: **1,15×**
- Правое поле акта шире: 12,5 мм vs ~10 мм в приказах

### Общие константы для генерации документов
```
font_name         = "Times New Roman"
font_size_body    = 14   # pt
line_spacing      = 1.15 # для приказов
line_spacing_act  = 1.00 # для актов
first_line_indent = 12.5 # мм (709 twips)
margin_left       = 20.0 # мм
margin_right_ord  = 10.0 # мм (приказы)
margin_right_act  = 12.5 # мм (акты)
margin_top        = 20.0 # мм
margin_bottom     = 20.0 # мм (приказы) / 12.5 мм (МБТ)
tab_date_number   = 132.5 # мм (строки даты/номера)
tab_header        = 142.5 # мм (строки заголовка)
```
